# 需求合同（冻结）

> 项目：BlueOS 手表「高中课表」应用
> 冻结时间：2026-09-05
> 冻结后变更必须声明「需求变更」并在本文件追加修正案。

## 1. 平台与形态
- 目标平台：vivo BlueOS（蓝河 OS）手表，圆形屏幕（watch-round，设计基准 designWidth 466）。
- 形态：普通蓝河手表应用（多页面 .ux），非表盘、非卡片。
- 分发：自用侧载（BlueOS Studio 蓝牙真机调试），不上架、不需要签名证书。

## 2. 用户与场景
- 受众：高中生。固定班级课表、有单双周、有早读/晚自习，抬腕即看、操作步数要少。
- 界面语言：中文。

## 3. 功能范围（MVP 全部包含）
1. 今日课程列表：周一至周日切换（表盘芯片点选），课程增删改查。
2. 单双周课程：按学期起始日自动计算周次与单双周；课程可标记 全部/单周/双周。
3. 自定义作息时间：时段（早读、各节课、午休、晚自习等）名称、起止时间、课/休类型可增删改。
4. 下节课倒计时：首页主卡显示当前课程剩余时间（含圆环进度）或距下一节开始的倒计时。
5. 考试与假期倒计时：条目增删改，首页胶囊显示距关键日期天数。

## 4. 非功能需求
- UI：iOS 深色质感（纯黑底、渐变卡片、描边、大圆角、克制动效）；圆屏安全区布局。
- 数据：纯本地存储（localstorage 主存 + internal://files 快照容错），无网络、无手机端同步。
- 科目录入：预设科目库（九科 + 体育/早读/自习等，带默认色），可换科目映射，不要求自由新增科目名。
- 周次：设置页选择学期第一周的周一，自动算周次。

## 5. 明确不做（MVP 边界）
- 网络同步、手机端配套、数据导出分享、上课提醒通知、上架签名、深浅色双主题、自由科目增删。

## 6. 关键技术事实依据
- 来源：bproject/BlueOS手表应用开发文档汇总.md（205 页官方文档，2026-09 提取）+ 本机 BlueOS Studio 2.2.1 安装内嵌工具链实证（hap-toolkit 1.9.14、watch 模板、模拟器引擎 watch.exe/cross.exe 通道注册表）。
- API 导入命名空间采用兼容层：优先 @blueos.*（真机，官方文档），回退 @system.*（模拟器引擎通道表实证）；manifest 同时声明两套 feature 名。

## 修正案

### 修正案 #1（2026-09-05，用户批准）：新增手机端课表导入通道
> **状态：已于同日被修正案 #2 整体撤销**，实现归档于 `attic/ble-import/`。

- **解封范围**：原「明确不做：网络同步、手机端配套」修正为——允许 **BLE 单向数据导入通道**：第三方 Android App（orbitV）作为 BLE central，向手表应用（BLE 外设/GATT 服务端）推送课表 JSON，手表端校验后经用户确认覆盖本地存储。
- **仍然不做**：orbitV 手机侧实现（仅交付对接规范文档）、双向同步/冲突合并（单向覆盖）、BlueXlink 互联通道（依赖 vivo 开放平台资质与运动健康）、网络/WebSocket 通道。
- **技术依据**：`blueos.bluetooth.ble` GattServer 全套 API 文档完整（createGattServer/startAdvertising/addService/subscribeCharacteristicWrite/sendResponse/notifyCharacteristicChanged）；对第三方 App 零资质要求。
- **交付物**：手表端接收功能 + `docs/ORBITV-PROTOCOL.md` 对接规范（GATT UUID、JSON Schema、分片协议、错误码）。

### 修正案 #2（2026-09-05，用户指示）：撤销手机端导入，编辑回归手表端
- **变更**：用户明确「不要在手机端通过扩展程序搭配手表应用编辑课表，就在手表上编辑」。修正案 #1 的 BLE 导入通道**整体撤销**，§4「无网络、无手机端同步」与 §5「明确不做」边界恢复为冻结原文。
- **处置**：实现从工程移除并完整归档至 `attic/ble-import/`（协议层/GATT 服务端/确认页/16 项单测/ORBITV 规范文档），恢复步骤见该目录 README。
- **影响**：课表所有编辑（课程/作息/考试假期/设置）均在手表端完成，已是现状，无需新开发；真机验证清单中 BLE 相关项作废。

### 修正案 #3（2026-09-05，用户指示）：删除单双周；编辑页改为按天视图 + 选择课程面板
- **删除单双周**：MVP §3.2「单双周课程」撤销。课程数据不再含 weekType 概念（旧存量数据中的 weekType 字段被容忍但忽略）；主页/周视图不再显示「单周/双周」；周次计算（第 N 周）保留。
- **编辑交互重构**（参考用户提供的「轻课表」截图）：编辑页 = 「‹ 周X ›」切换条 + 「第N节 + 科目」按天列表；点行弹出底部「选择课程」面板——预设科目块、自定义课程块、自定义输入框 + 确定按钮、红色「清空当前」按钮。
- **解封「自由科目增删」**：§4「不要求自由新增科目名」与 §5「明确不做：自由科目增删」修正为——允许在编辑面板新增自定义科目（同名复用、自动轮换取色、标记 custom）；科目不可删除（仅可清空某节课的安排）。
- **数据模型变化**：courses 条目为 `{subjectId, periodId}`；subjects 条目新增可选 `custom: true` 标记；DATA_VERSION 仍为 1（sanitize 兼容读取旧数据）。
